# Design reference

`powerbuilding_tracker_example.jsx` is the original single-file React prototype
provided by the project owner. It defined the 3-day powerbuilding program (squat,
bench press, deadlift + accessories) and the slate/emerald mobile-first visual
language.

It is kept here for provenance and design reference only. **It is not part of the
build** and is not a dependency of the Flutter app. The shipped implementation lives
in [`apps/strongsense`](../../apps/strongsense), and the design tokens are documented
in [`docs/design-system.md`](../design-system.md).
